# 🎬 دليل وهندسة تكامل TMDB ولوحة التحكم في نظام NEXORA
> **وثيقة معمارية وتشغيلية شاملة** | نظام NEXORA لإدارة مكتبات الوسائط (LAN-First)

---

## 1. الفلسفة المعمارية والهدف (Core Architecture)

يعتمد نظام **NEXORA** على مبدأ **السيادة المحلية والتشغيل أوفلاين (LAN-First & Offline Resilience)**:
- **الملفات الفيزيائية المحلية هي الأصل**: مسارات الفيديو، الأحجام، البصمات (SHA-256)، فحص التلف عبر FFmpeg، والجودة الفنية (Codecs / Audio / Subtitles) تأتي حصرياً من السيرفر المحلي.
- **TMDB هو مزود بيانات وصفية وإثراء بصري**: العناوين الإنجليزية والمترجمة، القصص والملخصات، البوسترات، الخلفيات، التصنيفات، طاقم العمل، التقييمات، والكلمات المفتاحية.
- **عزل أمني كامل للمفاتيح**: لا يتصل المتصفح بـ TMDB إطلاقاً؛ جميع الطلبات تمر حصراً عبر خادم Go المركزي (`server/internal/metadata`).

## 3. استراتيجية أوضاع جلب البيانات (Fetch Modes)

تتيح لوحة تحكم TMDB في NEXORA ثلاثة بروفايلات محددة مسبقاً بالإضافة إلى الوضع المخصص:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    مقارنة أوضاع جلب بيانات TMDB                              │
├───────────────────┬───────────────────────────────────┬────────────────────┤
│ الوضع             │ المحتوى المجلوب                   │ استهلاك النت/عنصر  │
├───────────────────┼───────────────────────────────────┼────────────────────┤
│ 1. Essential      │ العناوين + القصص + التصنيفات +    │ ~150 - 300 KB      │
│    (الأساسي)       │ التقييم + البوستر + الخلفية        │ (توفير 95%)        │
├───────────────────┼───────────────────────────────────┼────────────────────┤
│ 2. Standard       │ الأساسي + الممثلين نصياً +        │ ~350 - 450 KB      │
│    (القياسي)       │ التريلرات + المعرفات + المواسم     │ (الموصى به)        │
├───────────────────┼───────────────────────────────────┼────────────────────┤
│ 3. Full Catalog   │ القياسي + صور الممثلين الـ 20 +    │ ~3 - 5 MB          │
│    (الكامل)       │ معارض الصور + صور المقترحات        │ (نت مفتوح)         │
├───────────────────┼───────────────────────────────────┼────────────────────┤
│ 4. Custom         │ تخصيص يدوي لكل مفتاح تبديل        │ حسب الاختيار       │
└───────────────────┴───────────────────────────────────┴────────────────────┘
```

## 4. استراتيجيات تخزين ومعالجة الصور (Image Storage Strategies)

1. **الوضع الهجين (Hybrid Mode) — الافتراضي الموصى به**:
   - يقوم الخادم بتحميل البوستر الأساسي (`poster_path`) والخلفية (`backdrop_path`) وحفظهما كملفات فيزيائية في السيرفر لضمان عمل الواجهة والتصفح محلياً 100% دون اتصال بالإنترنت.
   - صور الممثلين والمعارض الإضافية تعرض عبر روابط TMDB CDN المباشرة دون استهلاك أي مساحة قرصية أو باندويث تنزيل على السيرفر.
   - **النتيجة:** توفير ما يزيد عن 90% من استهلاك النت مع الحفاظ على تجربة سينمائية مبهرة.

2. **وضع التخزين المحلي الكامل (Local Storage Mode)**:
   - تنزيل وحفظ كافة الصور المفعلة محلياً على القرص الصلب وتوليد مسارات محلية `/assets/images/tmdb/...`.
   - مناسب للصالات المعزولة كلياً عن شبكة الإنترنت (Air-gapped LAN).

3. **وضع الإنترنت فقط (Remote CDN Mode)**:
   - عدم تنزيل أي ملفات صور على السيرفر، والاعتماد بالكامل على روابط TMDB المباشرة.
   - يوفر مساحة التخزين على القرص الصلب بالكامل.

## 5. الحماية من الحظر وإدارة الكوتا (Rate Limiting & Quotas)

- **نظام التراجع الأسي الذكي (Exponential Backoff with Jitter)**: عند استلام رمز الاستجابة `429 Too Many Requests`، يوقف السيرفر الطلب تلقائياً ويعيد المحاولة مع فواصل زمنية متزايدة عشوائياً.
- **حد التحميل اليومي (Daily Bandwidth Quota)**: حماية السيرفر بحد أقصى يومي لاستهلاك البيانات (افتراضياً 500 MB/يوم)، مع عداد حي لمراقبة النسبة المئوية والتنبيه عند الاقتراب من الحد.
- **الكتابة الذرية للملفات (Atomic File Writes)**: حفظ الصور في ملفات مؤقتة والتحقق من حجمها وبصمة SHA-256 قبل نقلها إلى المسار النهائي لتجنب الصور التالفة عند انقطاع الاتصال.

## 6. نقاط الاتصال البرمجية الخاصة بـ TMDB (API Endpoints)

| المسار | الطريقة | الوظيفة |
| :--- | :--- | :--- |
| `/api/tmdb/settings` | `GET` | استرجاع إعدادات TMDB الحالية وأوضاع التخزين والكوتا |
| `/api/tmdb/settings` | `PUT` | تحديث إعدادات TMDB واللغات والحدود اليومية |
| `/api/tmdb/modules` | `GET` | قائمة كافة وحدات البيانات ومقدار استهلاك كل منها وحالتها |
| `/api/tmdb/modules` | `PUT` | تفعيل أو إيقاف وحدات معينة أو تبديل البروفايل بالكامل |
| `/api/tmdb/stats` | `GET` | إحصائيات الاستهلاك المباشرة (الطلبات، الباندويث، الكوتا) |
| `/api/tmdb/test` | `POST` | فحص اتصال الخادم بـ TMDB API وحساب زمن الاستجابة Latency |
| `/api/tmdb/configuration`| `GET` | جلب وقراءة أحجام الصور المعتمدة رسمياً من TMDB Config |
| `/api/tmdb/preview/{id}` | `GET` | محاكاة وحساب تكلفة إثراء عمل محدد قبل تنفيذ الطلب الفعلي |
| `/api/media/{id}/enrich` | `POST` | إثراء بيانات العمل باللغتين العربية والإنجليزية وتخزين الـ Snapshot |
