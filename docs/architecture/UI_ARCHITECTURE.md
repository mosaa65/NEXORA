# 🏛️ وثيقة الهندسة المعمارية الشاملة لإعادة هيكلة واجهات ونظام NEXORA
> **الدليل المعماري المرجعي للتقسيم، التوجيه (Routing)، نظام التصميم، وعزل لوحة الإدارة**

---

## 1. الفلسفة وحل معضلة تصنيف المحتوى (Taxonomy & Organization Architecture)

### ❓ المشكلة المطروحة:
كيف نقسم مئات التيرابايتات من الوسائط في الاستراحة؟ هل المسلسلات التركية، الأفلام الأجنبية، وأفلام الكرتون تُعرض كأقسام مستقلة أم فلاتر أم مجموعات مخصصة مع بوسترات بانر فاخرة؟

---

### 💡 الحل الهندسي الذهبي: نظام الطبقات الثلاث (Three-Tier Media Architecture)

لتحقيق تجربة سينمائية تضاهي **Netflix و Apple TV و Plex** دون إرباك قاعدة البيانات أو تكرار الملفات على الأقراص، يعتمد النظام على 3 طبقات تنظيمية مترابطة:

```
                               ┌────────────────────────────────────────┐
                               │   الطبقة 1: الأقسام الكبرى (Core)      │
                               │   أفلام | مسلسلات | أنمي | أطفال | ... │
                               └──────────────────┬─────────────────────┘
                                                  │
                       ┌──────────────────────────┴──────────────────────────┐
                       ▼                                                     ▼
        ┌──────────────────────────────┐                      ┌──────────────────────────────┐
        │ الطبقة 2: محاور المنشأ والسلاسل│                      │ الطبقة 3: الفلترة متعددة الأبعاد│
        │ (Origin Hubs & Collections)  │                      │ (Multi-Dimensional Filters)  │
        │ 👑 روائع الدراما التركية       │                      │ 🏷️ التصنيف: أكشن / دراما...   │
        │ 🌟 المسلسلات العربية والخليجية │                      │ 📅 السنة: 2026 / 2025...     │
        │ 🎬 أفلام هوليوود الأجنبية     │                      │ ⭐ التقييم: الأعلى تقييماً    │
        │ 🕷️ عالم سبايدرمان وديزني     │                      │ 📊 الحالة: مستمر / مكتمل     │
        └──────────────────────────────┘                      └──────────────────────────────┘
```

---

### 🎨 كيف تظهر صفحة "المسلسلات" للعميل بالاستراحة؟

عند ضغط العميل على قسم **"المسلسلات"** من القائمة الجانبية:

1. **البانر الترويجي التفاعلي (Hero Showcase Slider)**:
   - يعرض أحدث وأقوى المسلسلات المتصدرة بجودة 4K مع خلفية عريضة وزر "مشاهدة الآن" وزر "إضافة للمفضلة".
2. **محاور وسلاسل الدراما (Origin Hubs & Curated Cards)**:
   - **كارت بانر ضخم لـ "الدراما التركية"**: يحتوي على صورة فنية مجمعة لأبطال المسلسلات التركية مع عنوان مضيء وعدد المسلسلات المتوفرة.
   - **كارت بانر لـ "الدراما العربية والخليجية والمصرية"**.
   - **كارت بانر لـ "المسلسلات الأجنبية والعالمية (HBO / Netflix / Apple)"**.
   - **كارت بانر لـ "الدراما الآسيوية والكورية (K-Drama)"**.
3. **صفوف المحتوى الديناميكية (Smart Catalog Rows)**:
   - صف: 🔥 الأكثر مشاهدة في الاستراحة هذا الأسبوع.
   - صف: 👑 المسلسلات التركية المدبلجة والمترجمة.
   - صف: ⚡ أحدث الحلقات المضافة حديثاً على السيرفر.
   - صف: 🏆 المسلسلات الأعلى تقييماً (Top Rated IMDB/TMDB).
4. **شريط الفلترة الفوري (Instant Multi-Dimensional Toolbar)**:
   - فلتر الدولة/المنشأ: (الكل، تركي، عربي، أجنبي، كوري).
   - فلتر التصنيف: (أكشن، غموض، جريمة، كوميديا، رومانسي، تاريخي).
   - فلتر سنة الإنتاج: (2026، 2025، 2024...).
   - فلتر حالة العمل: (مكتمل، مستمر).
   - خيارات الترتيب: (الأحدث إضافة، الأعلى تقييماً، الأكثر مشاهدة، أبجدياً).

> **النتيجة**: عند فتح محور "الدراما التركية"، يفتح العميل صفحة مخصصة ببوستر أبطال الدراما التركية مع كامل المسلسلات التركية فقط مع فلاترها الخاصة، دون أي ازدواجية في تخزين الملفات الفيزيائية!

---

### 🧸 كيف تظهر صفحة "الأطفال والكرتون" وسلاسل الأفلام؟

- قسم **الأطفال والكرتون** يحتوي على:
  - سلاسل الأبطال الخارقين (عالم سبايدرمان، باتمان).
  - كلاسيكيات ديزني وبيكسار (ملكة الثلج Frozen، الحصان الوفي، حكاية لعبة Toy Story).
  - مسلسلات الكرتون وسبيستون المدبلجة (المحقق كونان، عهد الأصدقاء، أبطال الديجيتال).
- كل سلسلة لها **كارت مجموعة (Franchise Banner)** يجمع أجزاءها تلقائياً بالترتيب الزمني.

## 2. هندسة التوجيه واستعادة الحالة (Routing & Scroll Restoration)

### ❓ المشكلة الحالية:
النظام يعتمد على `activeView` داخل متغير حالة مفرد. عند الدخول لعمل ثم النقر على "رجوع"، يتم تصفير الصفحة والعودة للرئيسية وفقدان موضع التمرير والفلاتر.

### 💡 الحل الهندسي:
الاعتماد على **React Router v6** مع حفظ المعلمات في شريط العنوان (URL State Management) واستعادة التمرير (Scroll Restoration):

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          هيكل مسارات نظام NEXORA                            │
├──────────────────────────────┬──────────────────────────────────────────────┤
│ المسار (Route)               │ الوظيفة والشاشة المعروضة                     │
├──────────────────────────────┼──────────────────────────────────────────────┤
│ `/`                          │ الرئيسية (Dashboard & Media Feed)            │
│ `/catalog/:category`         │ صفحة القسم (مثال: `/catalog/series`)          │
│ `/catalog/:category/:hub`    │ صفحة المحور (مثال: `/catalog/series/turkish`) │
│ `/media/:id`                 │ صفحة تفاصيل العمل الكاملة (مع سجل الرجوع)    │
│ `/watch/:mediaId/:fileId?`   │ مشغل الفيديو السينمائي الكامل (LAN Player)   │
│ `/favorites`                 │ قائمة الأعمال المفضلة للزبون                 │
│                              │                                              │
│ 🔒 `/admin/login`            │ بوابة تسجيل دخول المشرفين المأمونة           │
│ 🔒 `/admin/dashboard`        │ لوحة المشرف العامة ومراقبة السيرفر           │
│ 🔒 `/admin/indexer`          │ أداة استعراض واختيار مجلدات الويندوز D:\, E:\│
│ 🔒 `/admin/media`            │ إدارة وتعديل وحذف أعمال المكتبة              │
│ 🔒 `/admin/categories`       │ إدارة الأقسام والتصنيفات                     │
│ 🔒 `/admin/tmdb`             │ لوحة تحكم وإعدادات TMDB والكوتا             │
│ 🔒 `/admin/migration`        │ معالج ترتيب ونقل وهيكلة الأقراص              │
│ 🔒 `/admin/quality`          │ كاشف الملفات المعطوبة والحلقات المفقودة      │
│ 🔒 `/admin/users`            │ إدارة المشرفين والصلاحيات وسجل العمليات      │
└──────────────────────────────┴──────────────────────────────────────────────┘
```

#### 🔄 آلية استعادة موضع التمرير والفلاتر (Scroll & Filter Restoration):
- عندما يتصفح المستخدم المسلسلات التركية ويصل للسطر 20 (`/catalog/series?origin=turkish&sort=rating`) ويدخل لمسلسل معين (`/media/45`):
- عند ضغط زر "رجوع" أو زر المتصفح، يرجع تلقائياً لنفس الرابط بنفس الفلاتر ونفس موضع التمرير بالضبط عبر خطاف `useScrollRestoration`!

## 3. نظام التصميم الموحد (Unified Glassmorphic Design System)

لمطابقة الصور التصورية بنسبة 100%، تم توحيد لوحة الألوان والمكونات:

### 🎨 لوحة الألوان الرسمية المعتمدة (Design Tokens):
- **الخلفية الأساسية (Deep Space Void)**: `#08070E` و `#0A0914`.
- **الزجاجي الشفاف (Glass Surface)**: `rgba(255, 255, 255, 0.03)` مع `backdrop-blur-xl` وحدود `rgba(255, 255, 255, 0.08)`.
- **البنفسجي الملكي (Royal Purple Accent)**: `#7C3AED` و `#9333EA`.
- **الوردي الفاقع (Neon Fuchsia Glow)**: `#C026D3` و `#E879F9`.
- **الأزرق الكهربائي (Electric Cyan)**: `#06B6D4` و `#38BDF8`.
- **الأخضر الزمردي (Emerald Online)**: `#10B981`.

### 🧩 مكتبة المكونات الموحدة (Reusable Component Library):
1. `<HeroShowcaseSlider />`: سلايدر بانر عريض تفاعلي بالأعلى لجميع أقسام المكتبة.
2. `<HubCard />`: كارت المحور الفاخر للبلدان والسلاسل (مثل بطاقة الدراما التركية).
3. `<MediaCard />`: كارت الفيلم/المسلسل الموحد بتأثير Neon Glow عند الوقوف بالفأرة، شارات الجودة 4K/1080p، سنة الإنتاج، ونسبة التقييم.
4. `<FilterToolbar />`: شريط الفلاتر السريعة الموحد لجميع الأقسام.
5. `<MediaDetailsModal />`: نافذة تفاصيل العمل السينمائية مع تبويبات (المواسم والحلقات، طاقم العمل، التريلرات، الأعمال المشابهة).
6. `<DirectoryPickerModal />`: مستعرض شجرة مجلدات ويندوز التفاعلي لاختيار مجلدات الفهرسة.
7. `<ProgressBarLive />`: شريط التقدم اللحظي لعمليات الفهرسة والنقل.

## 4. هندسة عزل لوحة الإدارة (Isolated Admin Portal Architecture)

### ❓ المشكلة الحالية:
لوحات الإدارة مدمجة داخل القائمة الجانبية لتصفح الزبائن بشكل عشوائي، ولا يوجد نظام أمان أو تسجيل دخول أو مؤشرات تحميل حية.

### 💡 الحل المعماري:
1. **العزل الكامل بين واجهة العميل ولوحة الإدارة (Clean Layout Separation)**:
   - واجهة الزبائن (`/`) تحتوي فقط على الأقسام الترفيهية مع تجربة سينمائية نقية بدون أي أزرار إدارية.
   - لوحة الإدارة (`/admin`) لها تصميم مستقل تماماً وقائمة جانبية متخصصة وهيدر إداري مع مؤشرات صحة السيرفر.
2. **نظام تسجيل الدخول والصلاحيات المتعددة (Multi-Admin RBAC & Audit Logs)**:
   - جدول `admin_users`: اسم المستخدم، كلمة المرور المشفرة (Argon2 / bcrypt)، الاسم، الدور (`superadmin`, `manager`, `operator`).
   - جدول `admin_audit_logs`: تسجيل هوية المشرف الذي أضاف، عدل، أو حذف أي عمل أو أجرى عملية نقل/فهرسة مع توقيت العملية.
3. **أداة استعراض واختيار مجلدات الويندوز (Native Windows Directory Tree Browser)**:
   - إضافة API endpoint: `GET /api/system/drives` و `GET /api/system/browse?path=D:\Media`.
   - نافذة منبثقة تفاعلية تتيح للمشرف تصفح أقراص السيرفر (D:\, E:\, F:\) والتنقل بين المجلدات واختيار المجلد بضغطة زر دون كتابة مسارات نصية.
4. **مؤشرات الفهرسة والنقل الحية (Real-Time Live Progress Streams via SSE)**:
   - استخدام Server-Sent Events (SSE) عبر نقطة `/api/tasks/progress` لبث تقدم الفهرسة وسرعة النقل ونسبة الإنجاز لحظة بلحظة للواجهة بشريط تقدم تفاعلي.

## 5. خطة التنفيذ المنهجية خطوة بخطوة (Phase-by-Phase Roadmap)

### 🚀 المرحلة 1: معمارية التوجيه وتثبيت React Router
- تثبيت حزمة `react-router-dom`.
- تقسيم التطبيق إلى مسارين رئيسيين: `CustomerCinemaLayout` و `AdminPortalLayout`.
- تفعيل خطاف استعادة موضع التمرير ومزامنة الفلاتر مع الـ URL.

### 🚀 المرحلة 2: محاور التصنيف والمجموعات (Origin Hubs & Collections)
- بناء واجهة محاور المسلسلات والأفلام (كروت الدراما التركية، العربية، الأجنبية، الكرتون).
- بناء شريط الفلترة متعدد الأبعاد الموحد (`FilterToolbar`).
- بناء الـ Hero Showcase Slider التفاعلي في رأس الصفحات.

### 🚀 المرحلة 3: عزل وبناء لوحة الإدارة الاحترافية (Admin Portal)
- بناء صفحة تسجيل دخول المشرفين `/admin/login`.
- بناء واجهة استعراض وتحديد مجلدات الويندوز التفاعلية (`DirectoryPickerModal`).
- إضافة قنوات البث الحي Server-Sent Events (SSE) لعرض شريط تقدم الفهرسة والنقل.
- إضافة جداول المشرفين وسجل العمليات (Audit Logs).

### 🚀 المرحلة 4: توحيد المكونات وتنظيف الكود (Refactoring & Polish)
- توحيد كود بطاقات الوسائط ونوافذ التفاصيل ومشغل الفيديو.
- تنظيف واستبعاد أي دوال أو مسارات غير مستخدمة.
- اختبار ومطابقة كافة الشاشات مع صور الـ Reference بدقة 100%.
