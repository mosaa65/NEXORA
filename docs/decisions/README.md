هذا المجلد يسجل قرارات موجودة ويمكن إثباتها من الكود الحالي. لا يعني `Existing / Verified` أن مالك المشروع أصدر قرارًا رسميًا جديدًا؛ بل يعني أن التنفيذ الحالي يثبت وجوده.
