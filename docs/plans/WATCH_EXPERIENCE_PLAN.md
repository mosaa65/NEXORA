# NEXORA Watch Experience — خطة التطوير الشاملة

> **الحالة:** قيد التنفيذ — نُفّذت المراحل W1–W6 (الأساس المحتوائي، شبكة الحلقات، الاقتراحات، مُنتقي الترجمة/السرعة، Next countdown، fullscreen queue، معاينة الشريط).
> **الفرع:** `feature/videojs-player-migration`
> **الأساس الحالي:** Video.js داخل شل NEXORA (`NexoraPlayer.jsx`) + شاشة تشغيل مخصصة (`WatchPage.jsx`) + مشغّل عائم عام (`MiniPlayerDock` + `PlaybackContext`).
> **الهدف:** تحويل شاشة المشاهدة إلى تجربة احترافية تنافس شاهد/نتفلكس/Prime، تتكيّف مع **كل** أنواع المكتبة (أفلام، مسلسلات، أنمي، برامج، رياضة… إلخ).

---

## 1. تحليل الوضع الحالي (من الكود الفعلي)

### 1.1 الموجود والمُثبَت
| المكوّن | الحالة |
|---|---|
| `NexoraPlayer.jsx` | Video.js + شل تحكم NEXORA: ±10s، كيبورد، ترجمات، ملء شاشة، PiP، حفظ تقدم، انتقال تلقائي، معاينة شريط زمني |
| `WatchPage.jsx` | حلقات على اليمين + فيديو يسار + ملخص أسفل + تبويب معلومات + تصغير للنافذة العائمة |
| `MiniPlayerDock.jsx` + `PlaybackContext.jsx` | مشغّل عائم يستمر عبر التنقل |
| `PlayableFilesExplorer.jsx` | **حُذف** في main — استُبدل بتصميم بطاقات داخل `MediaDetailsPage` |
| بطاقات المواسم/الحلقات (main) | بطاقات 3:4 للمواسم + بطاقات 16:9 للحلقات (still + بادجات + شرائح meta + زر تشغيل) |

### 1.2 بيانات متاحة من الـ API (مُثبَتة)
- تفاصيل العمل: `type`, `title_ar/en`, `plot_ar/en`, `release_year`, `rating`, `genres`, `poster_path`, `backdrop_path`, `parts_count`, `seasons[]`, `files[]`.
- لكل حلقة: `episode_number`, `episode_title_ar/en`, `overview_ar/en`, `still_path`, `air_date`, `runtime/duration`, `resolution`, `file_size`, `has_local_file`, `file_count`.
- لكل ملف: `id`, `file_path`, `duration`, `resolution`, `video_codec`.
- الاقتراحات: `GET /api/media/{id}/related` (رسم علاقات محلي — يشمل الأجزاء/السلاسل).
- القوائم: `GET /api/media?type=&category=&sort=&limit=`.
- **بحث حلقات منفصل**: `GET /api/episodes/search?q=` (فهرس Meilisearch مستقل).

### 1.3 مراجع تصميم يجب التوافق معها (من main)
- [`docs/card/card_plan.md`](../card/card_plan.md) — **نظام البطاقات الموحّد** (`UnifiedMediaCard` بنوافذ `context: catalog|carousel|season` و`variant: standard|compact`). مبادئ ملزمة:
  - مصدر البيانات **محلي وقاعدة NEXORA**؛ لا TMDB من المتصفح.
  - **لا أرقام وهمية** (لا 1080p أو تقييم افتراضي عند غياب البيانات).
  - سطر معلومات ذكي واحد يتغيّر حسب النوع (فيلم/مسلسل/موسم).
  - شارة حالة واضحة (مكتمل/مستمر/قادم/ملغي) بالنص لا اللون وحده.
  - الجوال بلا hover — البطاقة مكتملة وواضحة دائمًا.
- [`docs/design-system/DESIGN_SYSTEM.md`](../design-system/DESIGN_SYSTEM.md) — الألوان والمقاسات والمسافات.
- **بطاقات الحلقة في خطة المشاهدة يجب أن تُبنى بنفس المفردات** (`variant: compact` لشبكة الحلقات/الاقتراحات) لتظهر «من عائلة واحدة» مع الكتالوج.

### 1.4 الفجوات المكتشفة (ما ينقص حاليًا)
1. **`WatchPage` لا تتكيّف مع `type`** — تعرض "حلقات وملفات" دائمًا، بلا تمييز بين فيلم/مسلسل/أنمي/برنامج.
2. **لا قسم "أجزاء العمل"** للأفلام ذات `parts_count`.
3. **لا اقتراحات أسفل الفيديو**.
4. **مُنتقي ترجمة عادل** (زر CC يدوّر فقط — لا قائمة اختيار واضحة).
5. **معاينة الشريط الزمني غير موثوقة** (تعتمد FFmpeg عند الطلب؛ لا sprites مسبقة).
6. **لا "الحلقة التالية" بطاقة بارزة** كما في المنصات.
7. **لا قسم "شاهدته/التقدّم"** ولا استئناف مرئي واضح.

## 2. الرؤية الإبداعية

> **"NEXORA Watch" — سينما داخل المتصفح.**
> الفيديو هو البطل، والمحتوى حوله يتغيّر **ذكيًّا حسب نوع العمل المُشاهَد**، مع تفاعلات ناعمة وإحساس منصّة عالمية.

### مبادئ التصميم
1. **Content-aware** — الواجهة تتغيّر حسب `type` (فيلم ≠ مسلسل ≠ أنمي ≠ برنامج).
2. **Video-first** — الفيديو أكبر عنصر، والتفاصيل تُطوى/تنسدل.
3. **Ambient** — خلفية ضبابية من poster العمل تتغيّر مع التقدّم.
4. **Motion** — انتقالات framer-motion ناعمة، لا قفزات.
5. **Theme-neutral** — يعمل بثيم داكن/فاتح (كما هو نظام NEXORA) مع تباين كافٍ.
6. **RTL أصلي** — كل المقاسات والأسهم والاتجاهات تُبنى لـ RTL لا تُقلَب لاحقًا.

## 3. تصميم شاشة المشاهدة حسب النوع

### 3.1 القاعدة: `type` يقود التخطيط

```
media.type →
  movie        → "الأجزاء" (إن parts_count>1) + "أعمال ذات صلة"
  series       → "المواسم والحلقات" (مربعات still) + "الحلقة التالية" + "مسلسلات مشابهة"
  anime        → نفس المسلسل + تسميات (الموسم/الحلقة) + دعم (فاصل/HSub) + "أنمي مشابه"
  tv/program   → حلقات كجداول حلقات برامج + "برامج مشابهة"
  sport        → مقاطع/أحداث + "أحداث ذات صلة"
```

### 3.2 شبكة الحلقات (الأسلوب المطلوب — "مربعات")
بطاقة حلقة **مربّعة أنيقة** (مستوحاة من نتفلكس/شاهد) بثلاث طبقات:
1. **الصورة** (`still_path` 16:9) — بغلاف تدرّجي.
2. **داخل الصورة** (Overlay):
   - رقم الحلقة (شرارة أعلى-يمين).
   - زر **►** دائري (يظهر عند التحويم + على الحلقة النشطة).
   - **شريط تقدّم رفيع** أسفل الصورة إن كان هناك تقدم محفوظ (`nexora:playback:{fileId}`).
   - بادج "مكتملة ✓" عند 95%+.
   - بادج "N إصدارات" عند `file_count>1`.
3. **أسفل الصورة**: العنوان AR + EN (سطر واحد)، وشرائح صغيرة: التاريخ · المدة · الدقة · الحجم.

**الحالات:**
- غير متوفرة (`has_local_file=false`): رمادية + بلا زر تشغيل + شارة "غير متوفرة".
- النشطة: حلقة متوهّجة (ring + تدرّج بنفسجي).
- مكتملة: علامة ✓ خضراء.

### 3.2.1 عقد بيانات بطاقة الحلقة (مبنيّ على card_plan)
كل ما يُعرض يأتي من `/api` المحلي، بلا اختلاق:
```text
EpisodeCard (variant: compact)
  ├─ still_path        → الصورة (أو placeholder)
  ├─ episode_number    → شارة الرقم
  ├─ episode_title_ar/en → العنوان (عربي أولًا)
  ├─ runtime/duration   → المدة
  ├─ resolution         → الجودة (تُخفى إن غابت)
  ├─ file_size          → الحجم (يُخفى إن غاب)
  ├─ air_date           → التاريخ
  ├─ has_local_file     → متوفرة/غير متوفرة
  ├─ file_count         → "N إصدارات"
  └─ progress (localStorage) → شريط + حالة "مكتملة"
```
**قاعدة**: إن غاب الحقل لا نعرض قيمة بديلة وهمية؛ نحذف الشريحة.

### 3.3 الأجزاء (للأفلام) — "أجزاء العمل"
شريط أفقي بعنوان **"أجزاء العمل"** يظهر عند `parts_count > 1`:
- بطاقة جزء: بوستر 2:3 + رقم الجزء + سنة + مدة + زر تشغيل.
- مصدر البيانات: `getMediaRelated` مُفلترة على نوع "جزء/series" من نفس السلسلة.

### 3.4 قسم الاقتراحات (في الأسفل) — "شاهد أيضًا"
شريط أفقي متجاوب، **مصدره ذكي**:
- **أولوية 1**: `getMediaRelated(id)` (رسم العلاقات المحلي).
- **أولوية 2** (احتياطي): `getMediaList({ type: media.type, sort: "rating", limit: 12 })`.
- عنوان القسم يتغيّر حسب النوع: "أفلام مشابهة" / "مسلسلات مشابهة" / "أنمي مشابه".
- بطاقة اقتراح: بوستر 2:3 + عنوان + سنة + تقييم + نوع، مع تحويم يرفع البطاقة.

### 3.5 الشريط العلوي (Metadata Header)
- العنوان AR (كبير) + EN (صغير).
- شرائح: النوع · السنة · ★التقييم · التصنيف العمري · عدد المواسم/الأجزاء · الجودة.
- زر **"تشغيل"** أساسي + زر **"متابعة من HH:MM"** إن وُجد تقدم.

### 3.6 لوحة المعلومات تحت الفيديو
- الملخص (`plot_ar`) مع تبديل AR/EN.
- التصنيفات (chips).
- طاقم العمل (cast) — من `getMediaMetadataSnapshot` إن توفر.

## 4. تطوير مُشغّل Video.js (Shell)

### 4.1 مُنتقي الترجمة (Subtitle Picker) — بدل الدوران
- زر **CC** يفتح **قائمة منسدلة أنيقة** تعرض كل المسارات المتاحة (`label · srcLang`) مع علامة صح على المختار، وخيار "إيقاف".
- المصدر: `player.textTracks()` (المسارات المُمرَّرة عبر prop `tracks`).
- المقاس/المظهر: قائمة زجاجية منبثقة فوق الشريط (RTL).
- إصلاح: مزامنة حالة "الترجمة النشطة" مع الحالة الفعلية (لا الاعتماد على عدّاد فقط).

### 4.2 قائمة الجودة/الإصدارات (Sources Picker)
- عندما `file_count > 1`، يظهر زر **الجودة** يعرض الإصدارات المتاحة (1080p/720p/4K/حجم) لتلك الحلقة.
- تبديل المصدر يحفظ التقدم الحالي (`currentTime`) ويعيد تطبيقه.

### 4.3 معاينة الشريط الزمني — "يوتيوب-style" موثوقة
- **المسار الحالي**: `preview?at=bucket` (FFmpeg عند الطلب) — يعمل لكن غير فوري.
- **التحسين المقترح (مرحليًا)**:
  1. **فوري الآن**: تحسين debounce + placeholder + صورة مصغّرة محلية إن لم تتوفر.
  2. **لاحقًا (Backend)**: ألبوم **storyboard/sprites** يُولَّد مرة واحدة (`preview/sprite.jpg` + ملف أوقات)، فيصبح التحويم فوريًا بلا طلبات FFmpeg.
- إظهار الوقت فوق المعاينة + خط رأسي على الشريط عند موضع المؤشر.

### 4.4 أزرار وأفعال المشغل (إعادة تصميم)
- شريط سفلي واحد أنيق (كما بنيناه) مع:
  - تشغيل/إيقاف، ±10s، الوقت، **شريط تقدّم بفصول (chapters)** إن توفرت، الصوت، الترجمة (قائمة)، الجودة (قائمة)، السرعة، PiP، ملء شاشة.
- **Next episode** في نهاية الحلقة: بطاقة عائمة "الحلقة التالية تبدأ خلال 10…9" مع زر تشغيل فوري، كما في المنصات.
- **إشعار 10-second skip** (Toast) عند الضغط على ±10s.
- **حفظ فوري** عند الإيقاف/التبديل.

### 4.5 بقية الحلقات في fullscreen — "مربعات أنيقة"
- استبدال الشريط الحالي (`nexora-queue`) بـ **شبكة مربعات أنيقة** (grid) داخل drawer fullscreen:
  - كل بطاقة: still + رقم + عنوان + شريط تقدم + حالة (متوفرة/مكتملة).
  - حجم متناسق، مصمّم ليكون "حلو" لا مضغوطًا.

### 4.6 إصلاحات سلوكية
- إخفاء مؤشر الفأرة في الخمول (موجود) + إخفاء أثناء المشاهدة.
- مساحة الآمنة (safe area) للجوال.
- اختصارات موسّعة: `N` التالي، `Shift+,/.` سرعة، `T` الترجمة، `C` القائمة.

## 5. التصميم المتجاوب (كل الأجهزة)

| الجهاز | التخطيط |
|---|---|
| **شاشة كبيرة (≥1280px)** | عمودان: حلقات يمين (24rem) + فيديو يسار؛ اقتراحات بعرض كامل أسفل |
| **لابتوب/تابلت أفقي (1024–1280)** | عمودان مضغوطان؛ بطاقات أصغر |
| **تابلت عمودي (768–1024)** | عمود واحد: فيديو ثم حلقات (تمرير) ثم اقتراحات |
| **جوال (≤768)** | ملء العرض: فيديو 16:9، تبويبات (الحلقات/الأجزاء/المعلومات)، شبكة حلقات 2 أعمدة، أزرار لمس ≥44px |

## 6. الثيم ونظام التصميم
- **الاعتماد الكامل على Design System** (`docs/design-system/DESIGN_SYSTEM.md`):
  - Tokens: `--color-primary` (#7C3AED), `--color-accent` (#C026D3), `--color-success/warning/danger`, `--bg-base` (#08070E), `--bg-card` (#0E0C1A), `--border-default`.
  - الثيمات: `design-system/themes/dark.css` و`light.css` عبر `ThemeContext`.
- **إعادة استخدام مكوّنات `components/ui/`** في المشغل بدل بناء أزرار/شارات من الصفر:
  - `Button` لأزرار تشغيل/متابعة، `Badge` لشارات الحالة/النوع، `ProgressBar` لشريط الحلقة، `Spinner` للتحميل، `Modal` للتوابع إن لزم.
- **لا ألوان صلبة مكتوبة يدويًا** إلا عند الضرورة داخل المشغل (layer الخاص بالفيديو) — تُدار عبر Tokens.
- تباين AA على الأقل، وحالات (نجاح/تحذير/خامل) واضحة في الثيمين.

## 7. خطة التنفيذ المرحلية (Roadmap)

### المرحلة W1 — الأساس المحتوائي (Content-aware shell)
- دعم `type` في `WatchPage` + تسميات ديناميكية.
- الشريط العلوي الجديد + زر متابعة.

### المرحلة W2 — شبكة الحلقات "المربعات"
- مكوّن `EpisodeCard` جديد (still + overlay + تقدم + حالات).
- تبويبات (الحلقات/الأجزاء/المعلومات) على الجوال.

### المرحلة W3 — الاقتراحات + الأجزاء
- قسم "شاهد أيضًا" (related + fallback).
- قسم "أجزاء العمل" عند `parts_count>1`.

### المرحلة W4 — تطوير المشغل
- مُنتقي الترجمة + الجودة.
- Next-episode countdown + toasts.
- شريط/فصول محسّن.

### المرحلة W5 — المعاينة
- تحسين المعاينة فوريًا (fallback ذكي) + خطة sprites backend لاحقًا.

### المرحلة W6 — fullscreen queue
- شبكة المربعات الأنيقة بدل الشريط.

### المرحلة W7 — الثيم + التجاوب + التلميع
- متغيرات الثيم، حالات فارغة، حركات ناعمة، اختبار على كل المقاسات.

## 8. خارج النطاق (لا ننفّذه الآن)
- Transcoding / HLS / DASH (انظر ADR-002 وADR-016).
- نقل حفظ التقدم إلى الخادم.
- تعديل تصميم `MediaDetailsPage` (خارج نطاقنا — يخصّ main/الفريق).

## 9. المخاطر
1. **اعتماد صور/بيانات TMDB**: بعض الحلقات بلا `still_path` → placeholder.
2. **`preview` endpoint ثقيل عند أول تحويم** → نبدأ بـ fallback، ثم sprites.
3. **تعدّد الإصدارات (`file_count>1`)**: تبديل المصدر مع الحفاظ على الموضع يحتاج اختبارًا دقيقًا.
4. **الاقتراحات**: إن كان `related` فارغًا نحتاج fallback بالتصنيف/النوع.

## 10. معايير النجاح
- كل نوع عمل يُعرض بتخطيطه الصحيح تلقائيًا.
- تحويم شريط الفيديو يُظهر معاينة (مصغّرة أو placeholder فوري).
- الترجمة تُختار من قائمة واضحة (لا دوران أعمى).
- اقتراحات مناسبة بالنوع تظهر أسفل الفيديو.
- fullscreen يعرض بقية الحلقات كمربعات أنيقة.
- البناء ينجح، والتصميم متجاوب على جوال/تابلت/لابتوب، وفي الثيمين.
