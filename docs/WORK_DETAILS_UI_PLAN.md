# خطة واجهة تفصيل العمل — المرحلة القادمة

> **يحتاج موافقتك قبل التنفيذ.** استبدال هذا الحجم من الواجهة تغيير معماري،
> وقواعد المشروع تطلب موافقة المالك قبل التغييرات واسعة الأثر.

---

## 1. ما وجدته فعليًا في الواجهة

### صفحة تفصيل العمل الحالية

| الملف | الأسطر | الحالة |
|---|---|---|
| `pages/MediaDetailsPage.jsx` | **1,024** | فيها **ثلاثة مصادر متوازية للمواسم** |
| `components/PlayableFilesExplorer.jsx` | 345 | مستكشف الملفات المحلي القديم |
| `components/ViewModeMenu.jsx` | 97 | زر "رموز / تفاصيل" الذي تريد حذفه |
| `components/MediaCollection.jsx` | 149 | بطاقات الأعمال (تبقى، وتحتاج إثراء) |

### المشكلة الجوهرية: ثلاثة مصادر متنافسة

من فحص الكود (`list_code_definitions`):

```js
seasonsList               // ← المواسم المحلية من قاعدة البيانات
seasonSnapshots           // ← مواسم TMDB المخزّنة
englishSeasonsByNumber    // ← نفس مواسم TMDB بالإنجليزية
englishEpisodesByNumber   // ← حلقات TMDB بالإنجليزية
```

الصفحة تحاول **التوفيق بين الثلاثة** في نفس الوقت — ولهذا تظهر "لخبطة
وعشوائيات" كما وصفت. النظام الآن يعرف كيف **يدمجهم في مكان واحد**، فالواجهة
لا تحتاج ثلاثة مصادر.

### ما يوفره الـ API الآن (اختبرته فعليًا)

```powershell
GET /api/episodes/search?work=160&season=1&limit=5
```

يعيد، لكل حلقة:
```json
{
  "id": 61234, "work_id": 160, "season_number": 1, "episode_number": 4,
  "episode_title_en": "The Great Duel", "work_title_en": "One Piece",
  "overview_en": "...", "still_path": "/abc.jpg",
  "air_date": "1999-12-15", "runtime": 24,
  "has_local_file": true, "file_count": 2,
  "resolution": "1080p", "file_size": 2147483648, "duration": 1440,
  "enriched_from": "provider"
}
```

**هذا كل ما تحتاجه البطاقة** — ولا يحتاج الصفحة الجمع بين ثلاثة مصادر.

| القياس الفعلي | النتيجة |
|---|---|
| حلقات `One Piece` الموسم 1 | **61 حلقة** |
| حلقات بلا ملف محلي (`local=false`) | **1,000 حلقة** = "قيد الإضافة" |
| مواسم مُثراة | 187 |
| حلقات مُثراة | 6,132 |

## 2. الخطة المقترحة

### المرحلة 1 — مصدر واحد للمواسم والحلقات

`MediaDetailsPage` الحالية: **1,024 سطرًا**
`MediaDetailsPage` الجديدة: **~420 سطرًا** (مصدر واحد + تصميم TMDB)

**ما تفعله:**
```text
GET /api/media/{id}                    ← بيانات العمل (اسم، وصف، بوستر)
GET /api/episodes/search?work={id}     ← كل المواسم والحلقات من فهرس واحد
```

**لماذا أنظف:**
- لا توفيق بين مصادر — كل حلقة تأتي مُثراة ومُدمجة سلفًا
- الفلترة حسب الموسم تصبح **طلب فهرس** لا مسحًا في الذاكرة
- البحث داخل حلقات العمل يصبح متاحًا مجانًا (`?q=`)

### المرحلة 2 — تصميم TMDB للمواسم والحلقات

```text
┌─────────────────────┐
│  [بوستر]  One Piece                                 │
│           مسلسل · 1999 · 23 موسومًا · 1,181 حلقة     │
│           ── قائمة المواسم (شرائح أفقية) ──          │
│           [الموسم 1] [الموسم 2] [الموسم 3] ...      │
├─────────────────────┤
│  ┌──────┐  الحلقة 4 · The Great Duel                │
│  │صورة │  1999-12-15 · 24 دقيقة · 1080p · 2.0 GB   │
│  │حلقة │  وصف الحلقة…                              │
│  └──────┘  [▶ تشغيل]                                │
├─────────────────────┤
│  ┌──────┐  الحلقة 5 · الحلقة القادمة                │
│  │صورة │  ─────────  قيد الإضافة  ─────────         │
│  │افتراض│  لم تُضف بعد إلى المكتبة                   │
│  └──────┘                                          │
└─────────────────────┘
```

**قرارات بصرية مقترحة:**

| العنصر | القرار | السبب |
|---|---|---|
| **"قيد الإضافة"** | شريط رقيق + نص رمادي أنيق، بلا زر تشغيل | واضح وليس مزعجًا |
| **الصورة الافتراضية** | استخدم `nexora-library-backdrop.PNG` الحالي | موجود في المشروع |
| **معلومات البطاقة** | `التاريخ · المدة · الدقة · الحجم` في سطر واحد | كما تريد، مثل بطاقة العمل |
| **الحلقة بملفات متعددة** | تُعرض الدقة الأعلى + "إصداران" | لا تُكرر البطاقة |
| **الفصل 0 (Specials)** | يبقى كشريحة موسم عادية | 550 حلقة موجودة فيه |

### المرحلة 3 — الحذف المطلوب

| الملف | القرار | السبب |
|---|---|---|
| `components/PlayableFilesExplorer.jsx` | **حذف** | مستكشف الملفات المحلي القديم |
| `components/ViewModeMenu.jsx` | **حذف** | زر "رموز / تفاصيل" |
| منطق `handleCopyFiles` / `onCopySelected` | **حذف** | النسخ والتحديد |
| `englishSeasonsByNumber` و`englishEpisodesByNumber` | **حذف** | مصدران مكرران |
| `client/src/components/MediaCollection.jsx` | **يبقى + إثراء** | بطاقات الأعمال |

**قبل الحذف أتحقق أن لا مستخدم آخر:** بحثت ووجدت `PlayableFilesExplorer`
مستخدمًا في `MediaDetailsPage` فقط، و`ViewModeMenu` كذلك. فالحذف آمن.

### المرحلة 4 — بطاقات غنية

بطاقة العمل تُظهر حاليًا: البوستر، الاسم، النوع.

**المقترح إضافته** (البيانات متاحة من `/api/media`):
```text
[بوستر]  One Piece
         مسلسل · 1998
         23 موسومًا · 1,181 حلقة
         أعلى دقة: 1080p · 87.4 GB
```

**رأي:** أُضيف `أعلى دقة` و`الحجم` في سطر صغير. وأترك المدة للأفلام فقط
(بلا مواسم)، لأن مدة مسلسل لا معنى لها.

## 3. القرارات المطلوبة منك

### ⚠️ قرار 1 — الموافقة على الاستبدال

| الخيار | الأثر |
|---|---|
| **أ. استبدال كامل** ✅ موصى به | 1024 → ~420 سطرًا، مصدر واحد، تصميم TMDB |
| **ب. تعديل تدريجي** | أبقي البنية وأزيل المصادر المكررة فقط |

**توصيتي: (أ)** — لأن دمج ثلاثة مصادر في واحد **يُبسّط** لا يُعقّد، والبناء
من الصفر أوضح من ترقيع 1024 سطرًا.

**سؤالي:** موافق على (أ)؟

---

### ⚠️ قرار 2 — الحذف

| الملف | هل أُحذفه؟ |
|---|---|
| `PlayableFilesExplorer.jsx` (345 سطرًا) | **؟** |
| `ViewModeMenu.jsx` (97 سطرًا) | **؟** |
| منطق النسخ/التحديد | **؟** |

**توصيتي: نعم للثلاثة** — لأنها التصميم القديم الذي لا تريده.

**لكن:** لو أردت الرجوع لاحقًا، الحذف في Git يبقى في التاريخ.

**سؤالي:** موافق على الحذف؟

---

### ⚠️ قرار 3 — "قيد الإضافة"

**كيف تُعرض الحلقة غير المتوفرة؟**

| الخيار | الشكل |
|---|---|
| **أ. في نفس القائمة، رمادية** ✅ موصى به | الحلقة تظهر بترتيبها الطبيعي بلا زر تشغيل |
| **ب. في قسم منفصل "قادم"** | فصل بصري أوضح لكن يكسر ترتيب المواسم |
| **ج. مخفية افتراضيًا مع زر "إظهار"** | أنظف لكن المستخدم لا يعرف أنها موجودة |

**توصيتي: (أ)** — الترتيب الطبيعي مهم: الحلقة 5 موجودة عند المزود فتظهر في
مكانها. الفصل يكسر التسلسل.

**سؤالي:** أي خيار تفضّل؟

---

### ⚠️ قرار 4 — البحث داخل العمل

المصدر الجديد يسمح بالبحث في حلقات عمل واحد مجانًا.

**سؤالي:** هل أُضيف مربع بحث داخل صفحة العمل؟ (يبحث في عناوين حلقات هذا العمل فقط)

**توصيتي: نعم** — ميزة مجانية تقريبًا، ومفيدة لمسلسل بـ 1,181 حلقة.

---

## 4. ما لن يتغير

- `/api/media/{id}` يبقى كما هو (تُوسَّع استجابته بـ `best_resolution` و`total_size`)
- `MediaCollection.jsx` يبقى — يُثرى فقط
- المشغل (`VideoPlayer.jsx`) لا يُلمس — يعمل ومُختبر
- التصفح والبحث العام لا يُلمسان

---

## 5. الحجم والمخاطرة

| المرحلة | الحجم | المخاطرة |
|---|---|---|
| 1. مصدر واحد | متوسط | **متوسطة** — مسار حرج للمستخدم |
| 2. تصميم TMDB | كبير | منخفضة — عرض فقط |
| 3. الحذف | صغير | منخفضة — مُتحقق أن لا مستخدم آخر |
| 4. بطاقات غنية | صغير | منخفضة |

**التحقق:** سأبني واختبر في متصفح حقي (`browser-automation`) على
`One Piece` (23 موسمًا، 1,181 حلقة) — عمل غني يكشف أي مشكلة في التخطيط أو
الأداء.
