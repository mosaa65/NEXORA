# دراسة الحاوية الرئيسية الموحّدة — NEXORA

## الهدف

إنشاء مكوّن واحد اسمه المقترح `ShowcaseHero` يستخدم في الرئيسية والأقسام والمجموعات والنتائج المفلترة. ليس بطاقة فيلم مكبّرة؛ بل مساحة تحريرية تعرض «سبب وجود هذه المجموعة» وتدعو المستخدم للدخول إليها.

```text
ShowcaseHero
  ├─ mode: featured | collection | category | filter
  ├─ slides: محتوى قابل للدوران
  ├─ theme: لون/هوية المجموعة
  └─ actions: فتح المجموعة أو عرض كل الأعمال
```

## قاعدة البيانات أولاً

لا تُنشأ المعلومات في المتصفح ولا تستدعي TMDB عند العرض. كل شريحة تقرأ من API المحلي:

| النوع | المصدر المخزن | ما يظهر |
|---|---|---|
| عمل مميز | `media_items` + ملخص البطاقة | backdrop، العنوانان، السنة، التقييم، الحالة، النوع، التصنيف |
| قسم | `categories` + إعدادات العرض | عنوان القسم، الوصف، العدد، صورة خلفية محلية/مخزنة |
| مجموعة | جدول collections مقترح | اسم المجموعة، وصف قصير، صورة group artwork، عدد الأعمال، قواعد الفلترة |
| فلتر | طلب قائمة API | عنوان فلتر مثل «أحدث الأنمي»، العدد، صورة مختارة من أعمال النتيجة |

## أنواع الاستخدام

| الموضع | الغرض | الصورة | النص |
|---|---|---|---|
| الرئيسية | العمل المميز الآن | backdrop للعمل | عنوان العمل + وصف قصير + حالة + بيانات حقيقية |
| قسم الأنمي | استكشاف نوع المحتوى | collage مصمم أو backdrop أنمي متغير | «عوالم الأنمي» + وصف القسم + عدد الأعمال |
| المسلسلات التركية | مجموعة تحريرية | artwork جماعي مرخّص/محلي، لا صور عشوائية | عنوان المجموعة + سبب التجميع + العدد |
| أطفال/كرتون | عالم عائلي | collage شخصيات محفوظ محلياً | عنوان لطيف + العمر/التصنيف إن توفر |
| نتيجة فلتر | تأكيد سياق النتيجة | أفضل backdrop من النتائج، وإلا صورة المجموعة | اسم الفلتر + العدد + فرز نشط |

## ما يعرض وما لا يعرض

- يعرض شارة نوع أو اسم المجموعة، حالة حقيقية عند كونها شريحة عمل، و2–4 حقائق فقط.
- يعرض العنوان العربي أولاً، والإنجليزي تحته أو وحده LTR عند غياب العربية.
- لا يعرض زر تشغيل في الـhero؛ يفتح التفاصيل أو المجموعة، والتشغيل داخل التفاصيل فقط.
- لا يعرض حجم الملفات في Hero المجموعة؛ الحجم خاص ببطاقة العمل.
- لا يعرض عدد حلقات المسلسل؛ بطاقة الموسم فقط تعرض الحلقات.
- لا يعرض بيانات من TMDB إن لم تكن محفوظة محلياً.

## الحركة والاستجابة

- انتقال crossfade مع إزاحة خفيفة: 250–350ms، متوقف عند `prefers-reduced-motion`.
- تدوير تلقائي 8 ثوانٍ فقط عند وجود أكثر من شريحة، ويتوقف عند التفاعل أو hover/focus.
- جوال: ارتفاع 340–400px، النص في الأسفل، أزرار بعرض مريح.
- سطح المكتب: 420–520px، مساحة نص لا تتجاوز 45% من العرض.
- الصورة تغطي الحاوية، مع `object-position` قابل للحفظ لكل artwork لتفادي قصّ الوجوه.
