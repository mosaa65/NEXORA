### 1. الهندسة المعمارية للنظام وواجهات المستخدم
- **[دليل الهندسة المعمارية الشاملة لإعادة هيكلة الواجهات والتصنيف والتوجيه وعزل الإدارة](architecture/SYSTEM_REFACTORING_AND_UI_ARCHITECTURE.md)**:

### 2. تكامل وبوابة TMDB ولوحة التحكم
- **[دليل وهندسة تكامل TMDB ولوحة التحكم](tmdb/TMDB_ARCHITECTURE_AND_CONTROL.md)**:
  - الفلسفة المعمارية للعمل دون اتصال (LAN-First & Offline Resilience).
  - خريطة البيانات التفصيلية واستراتيجيات الأوضاع (Essential, Standard, Full).
  - أوضاع معالجة وتخزين الصور (Hybrid, Local, Remote).
  - آليات التراجع الأسي (Backoff) والحماية من Rate Limiting وإدارة الكوتا اليومية.
  - توثيق نقاط الاتصال البرمجية (API Endpoints).

### 3. هندسة وتصميم قاعدة البيانات
- **[دليل المواصفات الهندسية ومخطط قاعدة البيانات PostgreSQL](database/DATABASE_ARCHITECTURE_AND_SCHEMA.md)**:
  - المخطط المعماري الشامل وعلاقات الجداول (ERD).
  - المواصفات الدقيقة لكافة الجداول: `categories`, `media_items`, `seasons`, `video_files`, `storage_disks`, `tmdb_settings`, `metadata_snapshots`, `tmdb_usage_log`.
  - استراتيجيات الفهرسة المتقدمة (`GIN JSONB`, Compound Unique Indexes, B-Tree).
  - استعلامات الصيانة وكشف الحلقات المفقودة والملفات المكررة وحساب استهلاك الباندويث.
