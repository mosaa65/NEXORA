# 🧭 NEXORA Navigation, Header & Filter System

> الفلسفة المعمارية: **"مكونات مستقلة، قابلة لإعادة الاستخدام، متجاوبة بالكامل، وتخدم تجربة السينما المنزلية الفاخرة"**.

---

## 🏛️ نظرة عامة على المكونات

تمت إعادة هيكلة وتوحيد مكونات التنقل والبحث والفلترة في NEXORA لتعمل وفق أعلى معايير التصميم والتجاوب:

```
client/src/
├── components/
│   ├── TopBar.jsx            # الهيدر العلوي الموحد مع الشعار الرسمي ومحرك البحث
│   ├── FilterToolbar.jsx     # شريط الفلترة والبحث المتقدم للأقسام والمحاور
│   └── layout/
│       ├── SideNavigation.jsx# القائمة الجانبية الموحدة
│       └── navigation.css    # أنماط التنقل المتجاوبة
└── pages/
    ├── CategoryPage.jsx      # صفحات الأقسام (أفلام، مسلسلات، أنمي)
    ├── MediaDetailsPage.jsx  # صفحة تفاصيل العمل مع زر العودة الذكي
    └── SmartHubPage.jsx      # صفحات المحاور الذكية
```

## 🎨 1. الهيدر العلوي (TopBar)

### المواصفات التصميمية:
- **الشكل (Shape)**: تصميم كبسولي عائم (`rounded-full` / `rounded-2xl`) مع زوايا ناعمة وتأثير زجاجي فائق `backdrop-blur-2xl`.
- **الهوية البصرية (Branding)**: استخدام الشعار الرسمي الحصري `/nexora-brand-logo.PNG` مباشرة مع إزالة النصوص الزائدة والشعارات الهندسية القديمة.
- **التجاوب (Responsiveness)**:
  - **الجوال**: زر قائمة واضح، حقل بحث مدمج ذكي، وشعار متناسق الحجم.
  - **التابلت واللابتوب والـ PC**: توزيع متناسق، حقل بحث مريح مع تباين قراءة عالي، وقائمة نتائج فورية منبثقة.

### محرك البحث في الهيدر (Search Engine):
- حقل بحث بخلفية داكنة معتمة قليلاً لمنع التداخل مع الخلفيات الشفافة وضمان قراءة سلسة للنصوص.
- قائمة نتائج حية (`Live Dropdown`) تعرض:
  - صورة البوستر.
  - العنوان العربي والإنجليزي.
  - سنة الإنتاج ونوع العمل وجودته.
  - زر تشغيل فوري وزر فتح التفاصيل.

## 🔍 2. شريط الفرز والبحث المتقدم (FilterToolbar)

### المواصفات الوظيفية والتصميمية:
- **كرت زجاجي موحد**: حاوية أنيقة مدمجة تتناسب مع الثيم الليلي لـ NEXORA.
- **حقل البحث المحلي**: للبحث الفوري السريع داخل محتوى القسم المفتوح.
- **أشرطة الفلاتر الدائرية (Pills)**:
  - **المنشأ**: أزرار دائرية متوهجة عند التحديد لتصفية المحتوى حسب الدولة (تركي، عربي، أجنبي، كوري، هندي، ياباني...).
  - **التصنيف**: أزرار تصنيف سريعة (أكشن، دراما، كوميديا، خيال علمي...).
  - **التمرير السلس**: دعم التمرير الأفقي باللمس والماوس (`horizontal-scroll`) لجميع مقاسات الشاشات دون تشويه التخطيط.
- **الترتيب والإحصائيات**: قائمة منسدلة أنيقة للترتيب حسب (الأحدث، الأعلى تقييماً، سنة الإنتاج، أبجدياً) مع شارة عدد النتائج الفعلية.

---

## 🎬 3. صفحة تفاصيل العمل (Media Details Page)

- إزالة حقل البحث والشعار المكرر من داخل صفحة التفاصيل لتوفير مساحة تركيز للعمل الفني والبوستر.
- توفير **زر عودة ذكي (Back Navigation)** بتصميم زجاجي كروي/كبسولي في أعلى الصفحة يُمكّن المشاهد من العودة بسلاسة إلى القسم السابق بلمسة واحدة.
